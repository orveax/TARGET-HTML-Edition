## Evidence

- Bootstrap 5.3.8 LTR + RTL CSS and bundle JS are packaged locally under `assets/vendor/bootstrap/`.
- Bootstrap license notice is shipped.

### ORIGEX foundations
- F01–F07 are implemented through `origex-tokens.css` and `origex-foundation.css`.
- P01–P11 and C01–C28 are mapped to central implementation in `origex-components.css` and `docs/M1-COMPONENT-IMPLEMENTATION-MAP.md`.
- S01–S06 are implemented centrally.
- N01–N04 are implemented in `origex-shell.css` + `origex-ui.js`.
- PT01–PT06 exist as ORVEAX-owned local SVG assets.
- `config.js` and `config-engine.js` remain enhancement/config layers and do not generate core page UI.

### AR / EN QA surfaces
- `preview/m1-components-ar.html` uses `lang="ar"`, `dir="rtl"`, local Bootstrap RTL and the ORIGEX layers.
- `preview/m1-components-en.html` uses `lang="en"`, `dir="ltr"`, local Bootstrap LTR and the ORIGEX layers.
- Both surfaces use local runtime assets, canonical fictional demo disclosure and `noindex,nofollow`.
- Navigation, tabs, accordion, filters, upload state, config hooks and reduced-motion behavior are implemented centrally.
- Mega-menu positioning context was corrected centrally in N01 before M1 closure.
