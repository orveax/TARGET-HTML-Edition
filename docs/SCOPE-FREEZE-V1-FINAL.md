Language: Arabic-first RTL + English LTR

## 1. V1 Scope Rule

ORIGEX V1 ships the approved Main Features only.

Additional Features are intentionally excluded from V1 implementation and moved to the V1.1 Expansion Backlog. They are not deleted; they are deferred.

No new V1 page, feature family, or major dependency may be added after this freeze without an explicit Scope Change.

## 2. Product Strategy

ORIGEX V1 is a premium commercial HTML template designed as a focused market test for B2B food trading companies, importers, distributors, wholesalers, manufacturers, suppliers and brand owners.

Core differentiation:
- Arabic-first RTL architecture.
- Complete English LTR counterpart.
- Vertical-specific food trading UX.
- Product, supplier, market and RFQ systems.
- Simple customization through `config.js`.
- One global ORIGEX design system with Page Design Profiles.
- Fast HTML/CSS/Vanilla JS implementation.
- Strong beginner-friendly documentation.

## 4. Global V1 Features

- Arabic-first RTL + complete English LTR.
- Tajawal + Manrope typography hierarchy.
- Responsive design system.
- Global design tokens.
- Page Design Profiles.
- Mega menu and mobile drawer.
- `config.js` customization layer.
- Search/filter/tabs/accordion interactions where required by the frozen Main Features.
- Forms and validation.
- Announcement bar, floating WhatsApp and back-to-top controls.
- Accessibility baseline and reduced-motion support.
- SEO baseline, canonical/hreflang structure and structured-data placeholders.
- Documentation, licensing register, credits and changelog.

## 5. V1 Exclusions

- All Additional Features listed in the V1.1 Expansion Backlog.
- Ecommerce cart, checkout and payment.
- Customer accounts/authentication.
- Admin dashboard.
- Page builder integration.
- React/Vue runtime dependency.
- Heavy animation frameworks as a core dependency.
- Dark mode.
- Generic Team and Careers standalone pages.

## 6. Change Control

After this freeze:
- UX polishing does not reopen scope.
- Accessibility, performance, responsive and RTL fixes do not reopen scope.
- Content refinement inside an approved Main Feature does not reopen scope.
- Any new page or feature family requires a formal Scope Change or moves to V1.1+.
