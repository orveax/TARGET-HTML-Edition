# ORIGEX — 48-Hour ThemeForest Launch Mode

**Product:** ORIGEX / ORX-P01  
**Owner:** ORVEAX  
**Objective:** Make ORIGEX submission-ready and upload it to ThemeForest within the 48-hour build window.

> Marketplace approval timing is controlled by Envato review and is not part of this internal deadline.

## Operating Rule

No uncontrolled redesign loops.

Each page follows:

1. Page purpose
2. Main Features
3. Additional Features
4. Arabic RTL notes
5. English LTR counterpart
6. Responsive risks
7. Asset / licensing check
8. Build
9. Static QA
10. Visual QA when browser environment is available
11. Documentation entry
12. Fidelity matrix update

## Scope Control Under Deadline

A new idea enters V1 only when:
- it is critical to the B2B food-trading category, or
- it removes a likely buyer objection, or
- it materially improves ThemeForest presentation or usability.

Otherwise it is recorded for v1.1.

## Quality Rule

Quantity does not override quality. A smaller page set that is coherent, documented, bilingual, responsive and editable is preferable to a larger broken set.

## Submission Definition of Done

ORIGEX is submission-ready only when:

- Arabic and English entry points exist
- primary pages are coherent
- 404 and under-construction pages are designed
- documentation is publicly accessible
- live demo is functional
- downloadable ZIP is clean and organized
- asset rights are documented
- no client-specific TARGET data remains
- no critical broken link or missing local asset remains
- item presentation assets are ready
- version is tagged internally as `1.0.0 Submission Candidate`
